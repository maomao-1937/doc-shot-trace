# Evidence notes (2026-10-30)

User job: after a UI label rename, a technical writer needs to locate which existing Markdown screenshots might still show the old label. Repetition is plausibly per UI release, not measured. The fallback is manual image inspection or scripted recapture.

Direct voices: [July 2026 native-app technical writer](https://www.reddit.com/r/technicalwriting/comments/1urqhka/keeping_screenshotheavy_docs_current_especially/); [October 2026 screenshot maintenance discussion with multiple writers](https://www.reddit.com/r/technicalwriting/comments/1xcn4l0/lets_talk_screenshots/); [July 2026 Photo-Club-Hub maintainer issue](https://github.com/vdhamer/Photo-Club-Hub/issues/774). These show a recurring task over months and two channel categories, not purchasing intent or a predicted audience size. [Sentry's June 2026 screenshot-maintenance issue](https://github.com/getsentry/sentry-docs/issues/18242) is a continued implementation signal, not independent proof of demand for this product.

Alternatives checked before coding: [Tango documentation capture](https://www.tango.ai/product/it-documentation) (hosted; free entry with paid team-oriented features; browser/desktop capture workflow), [Sentry's repository-specific pipeline](https://github.com/getsentry/sentry-docs/issues/18242) (internal workflow), and the [DOSUD research approach](https://people.cs.vt.edu/~nm8247/publications/DOSUD2025.pdf) (trained stale-screenshot classifier, not a packaged general-use CLI in the source reviewed). These seriously weaken any claim of novelty. We found no reliable third-party user-review comparison for this exact narrow workflow; absence is not proof of a gap.

Difference to test: supply a known old/new label CSV, scan already-embedded local Markdown images with OCR, and get source links for human review. No current-screen access is needed, so the same workflow can cover native-app screenshots. This is a hypothesis. OCR misses, false matches, Markdown syntax gaps and private-image handling must be validated with real doc teams before adoption claims.

References read on 2026-10-30: [anthropics/knowledge-work-plugins](https://github.com/anthropics/knowledge-work-plugins) for knowledge-worker task framing, [msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) for independent product/UX/reality-check lenses, and newly found [getsentry/sentry-docs](https://github.com/getsentry/sentry-docs) and [vdhamer/Photo-Club-Hub](https://github.com/vdhamer/Photo-Club-Hub) for concrete source workflows. None of their code, prompts or images are copied. Full candidate and source-channel audit is in the local daily selection log, not part of this repository.
